How to speed up a slow computer

A slow computer doesn't always mean a new computer. Before you spend money, try these five things. Between them, they fix most of the slow machines I see.

By Zac Tassone, Managing Director of Zectron Web & IT Services

The short version

  • Restart it properly. Most slow computers haven't been restarted in weeks.
  • Turn off apps that start automatically and you don't need.
  • Keep at least 15 to 20 percent of your disk free.
  • Install pending updates, then restart again.
  • If it still has a spinning hard drive, an SSD upgrade is often cheaper than a new machine.

1. Restart, don't just close the lid

Closing the lid or pressing sleep isn't the same as restarting. Over days and weeks, programs leave things running in the background and memory fills up. Choose Restart from the Start menu on Windows or the Apple menu on a Mac at least once a week. If your computer tells you it's been up for 20 or 30 days, that's your first fix.

2. Clean up what starts automatically

Lots of programs add themselves to startup without asking: chat apps, printer tools, cloud sync and updaters. Each one slows the start and keeps using memory all day. On Windows, open Task Manager and look at Startup apps. On a Mac, go to System Settings, General, Login Items. Turn off anything you don't need running all the time. You can still open it when you need it.

3. Free up disk space

When a drive is nearly full, everything slows down, because the system has no room to work. Aim to keep at least 15 to 20 percent free. Empty the recycle bin, clear out the Downloads folder, remove programs you no longer use and move old photos and videos somewhere else. Windows Storage Sense and the Mac's storage settings will show you what's taking the space.

4. Install the updates

Pending updates often run in the background and slow things down until they're finished. Install everything waiting in Windows Update or Software Update, restart, and check again in case there's a second round. Updates also close security holes, so this one is worth doing even if speed isn't the issue.

5. Check the hardware before you replace it

If the computer is a few years old and still has a spinning hard drive, swapping it for a solid state drive (SSD) is the single biggest speed upgrade you can make. It often costs a fraction of a new machine. Adding memory (RAM) can help too. If the computer is very old, can't run a supported version of Windows or macOS, or the repair costs more than half of a new one, that's when it's time to replace it.

When it's time to get help

If a business computer is slow, it's worth having it checked properly. Slowness can also be a sign of a failing drive or something running that shouldn't be. A quick health check tells you whether it's worth fixing or time to plan a replacement.
